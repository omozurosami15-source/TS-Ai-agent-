Install

1. Press Download APK above and open the file. Allow "install unknown apps" if the phone asks.

2. Open TS Agent, tap SETTINGS and grant Accessibility, overlay, microphone and media permissions.

3. Optional: paste your own Anthropic API key for free-form tasks. Offline commands work without it.

4. Tap the mic and talk. Try: "open YouTube", "scroll down", "set timer 5 minutes".

[ Permissions and transparency ]

The app uses the Accessibility service so that, on your command, it can read the screen of other apps and tap. Screen text is sent only to complete your task, and only to the AI service using your own API key. Text in password fields is not sent. There is no account and no server of ours. You can turn the service off at any time in the phone Accessibility settings. The source code is public on GitHub.
