Get started

Install TS Agent

Download the latest published APK from the project’s GitHub Releases.

  1. Tap Download APK and open the downloaded APK file.
  2. If Android asks, allow installation from this source.
  3. Open TS Agent and review its permissions in Settings. Grant only the permissions needed for features you use.
  4. For AI-provider features, configure the provider and credentials in the app settings.
  5. Open the web version anytime using MISS SARA Web.

Permissions & transparency

You stay in control

Android accessibility, microphone, camera, overlay and media permissions are used by related features. Review each Android permission prompt and disable permissions you do not want to grant. AI-provider data handling depends on the provider configured in the app; consult that provider’s policy before sending sensitive information.
